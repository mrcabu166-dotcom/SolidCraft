# MicroDry-Safe — โรเตอร์ปั่นตากสไลด์ 20 ช่อง

**ภาษาไทย** | [English](README.en.md)

ใช้กับเครื่องปั่น Simplus 2L 300W (โถแก้ว) โดยใส่แทนชุดใบมีดเดิม
สถานะ: **ผ่านการทดสอบครบแล้ว ใช้งานจริงได้** (ตุลาคม 2026)

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `params.yaml` | ค่าจากเครื่องจริงและระยะเผื่อของเครื่องพิมพ์ ทุกค่ามีป้าย `measured` หรือ `estimated` |
| `slide_rotor.py` | สร้างโมเดล ตรวจกฎออกแบบ 28 ข้อ และ export ไฟล์ทั้งหมด |
| `output/stl/rotor_body.stl` | ตัวโรเตอร์ (เพลา + จานล่าง) หนักราว 102 g |
| `output/stl/rotor_top_ring.stl` | แหวนบน หนักราว 47 g |
| `output/stl/fit_test.stl` | ชิ้นทดสอบความพอดีของรูหมุดกับเบ้าเฟือง หนัก 13.7 g |
| `output/step/` | STEP ของทุกชิ้น และชุดประกอบที่มีสไลด์ 20 แผ่น |
| `output/png/` | ภาพ iso ภาพมุมบน และภาพตัดในโถ |
| `output/report.json` | ผลตรวจทั้งหมด |

สร้างใหม่ (รันจากโฟลเดอร์ `microdry`):

```bash
../.venv/Scripts/python slide_rotor.py
```

ถ้าไม่ต้องการภาพ ให้เติม `--no-render` ท้ายคำสั่ง ถ้ากฎออกแบบข้อไหนไม่ผ่าน สคริปต์จะหยุดและบอกชื่อกฎข้อนั้น

## ค่าที่วัดจากเครื่องจริง

| รายการ | ค่า (มม.) |
|---|---|
| ความสูงภายในโถ (ก้นโถถึงใต้ฝา) | 95 |
| รูฝาที่คอเพลาลอดผ่าน | Ø18 |
| หัวเฟือง | ปลายฟัน Ø9 / โคนฟัน Ø7 / 8 ฟัน / ฟันกว้าง 1.6 / ยาว 12 |
| หมุดก้นโถ | Ø6 สูง 15 ก้นโถเรียบ ไม่มีส่วนนูนรอบหมุด |
| เพลาเดิม | ยาว 110 ปลายล่างลอยจากก้นโถ 1 |

## ระยะเผื่อที่ทดสอบแล้ว

ทดสอบด้วยเครื่องพิมพ์และ PETG ชุดที่ใช้จริง (ค่าต่อข้าง)

| จุด | ค่า | ผล |
|---|---|---|
| รูหมุด (`pin_bore_clear`) | 0.15 | พอดี |
| เบ้าเฟืองพิมพ์ (`socket_clear_printed`) | 0.25 | พอดี (ลองที่ 0.20 แล้วแน่น) |
| รูหกเหลี่ยมของแหวน (`hex_clear`) | 0.15 | พอดี |
| ร่องสไลด์ (กว้าง 1.8) | — | สไลด์เสียบพอดี |

ถ้าเปลี่ยนเครื่องพิมพ์ ฟิลาเมนต์ หรือหัวฉีด ให้พิมพ์ `fit_test.stl` ทดสอบใหม่ก่อน แล้วปรับค่าทีละ 0.05

## ค่าสไลเซอร์ (PETG)

- ความหนาชั้น 0.2, ผนัง 4–5 รอบ, ผิวบน/ล่าง 5 ชั้น, infill gyroid 40% ขึ้นไป
- `rotor_body`:
  - ใช้ tree support **เฉพาะใต้จาน**
  - ใส่ support blocker ในร่องสไลด์ รูระบาย และรูหมุด
  - ใส่ modifier infill 100% ที่ความสูง 20 มม. บนสุดของเพลา (ตรงเบ้าเฟือง)
- `rotor_top_ring`: ไม่ต้องใช้ support
- ใช้ค่าชุดเดียวกับตอนพิมพ์ `fit_test`

## อะไหล่ที่ต้องซื้อ

- Heat-set insert M3 จำนวน 2 ตัว (ขนาดที่ออกแบบไว้คือ M3×5.7×4.6 ใช้รู Ø4.0)
- สกรูตัวหนอน (grub screw) M3×8 จำนวน 2 ตัว ใช้ M3×6 ได้ แต่**ห้ามยาว 10** เพราะหัวจะโผล่ไปชนสไลด์

## ขั้นตอนประกอบ

1. กด insert ลงในรูทั้ง 2 รูที่บอสของแหวน ใช้หัวแร้งราว 230–240 °C กดจนผิว insert เสมอพลาสติก
2. วางโรเตอร์ลงในโถ ให้รูที่ปลายล่างเพลาสวมลงหมุดก้นโถ
3. สวมแหวนลงบนหกเหลี่ยม ให้รอยบาก V ที่ขอบแหวนตรงกับรอย V ที่ขอบจาน ตั้งที่ 0° หรือ 180° ก็ได้ เลขช่องตรงกันทั้งสองแบบ
4. ขันสกรูตัวหนอนทั้ง 2 ตัวให้แน่น **ก่อนใส่สไลด์** เพราะแนวสกรูอยู่ตรงช่องเลข 1 พอใส่สไลด์แล้วจะเอาประแจเข้าไปไม่ได้
5. เสียบสไลด์ลงผ่านร่องของแหวนจนถึงก้นร่องในจาน **ใส่ทีละคู่ตามเลข** ช่องที่เลขเดียวกันอยู่ตรงข้ามกัน 180° (6. และ 9. มีจุดไว้กันสับสน)
6. ปิดฝา แล้วปั่น

ถอดออกให้ทำย้อนลำดับ: ดึงสไลด์ออกให้หมดก่อน แล้วค่อยคลายสกรูและยกแหวนขึ้น

## การใช้งานและดูแล

- **ใส่สไลด์เป็นคู่เสมอ** ถ้ามีสไลด์จำนวนคี่ ให้ใส่สไลด์เปล่าในช่องคู่ของมัน ห้ามปั่นตอนที่คู่ไหนมีแผ่นเดียว
- ระหว่างปั่นให้จับโถและกดฝาไว้ ถ้าเสียงเปลี่ยนหรือเริ่มสั่น ให้ปล่อยปุ่มทันที
- ที่ 2800 rpm ขอบนอกของสไลด์รับแรงราว 386 g (ดูตาราง RCF ในผลรันของสคริปต์)
- ตรวจทุก 5–10 ครั้งที่ใช้:
  - เบ้าเฟือง: มีขุยหรือเริ่มโยกหรือไม่
  - โคนร่องสไลด์ และรอบ insert: มีรอยร้าวขาวหรือไม่
  - แหวน: ยังล็อกแน่นอยู่หรือไม่
- ห้ามล้างด้วยน้ำร้อนเกิน 60 °C และห้ามเข้าเครื่องอบ เพราะ PETG จะอ่อนตัว
- ถ้าเบ้าเฟืองสึก ให้พิมพ์ `rotor_body` ใหม่ หรือแก้ `drive_method: metal_insert` ใน `params.yaml` เพื่อเปลี่ยนไปใช้เบ้าโลหะ

## ผลทดสอบ (ตุลาคม 2026)

| ขั้น | ผล |
|---|---|
| ทดสอบความพอดี: หมุด / เฟือง / หกเหลี่ยม / ร่องสไลด์ | พอดีทุกจุด |
| Insert + สกรู M3×8 ล็อกแหวน | ล็อกแน่น ไม่ขยับ |
| ปั่นเปล่า pulse | นิ่ง ไม่ขูด |
| สไลด์ 1 คู่ / ครบ 10 คู่ | นิ่ง สไลด์ไม่หลุด |
| สไลด์ 20 แผ่น ปั่น 30 วินาที | นิ่ง ไม่สั่น |
| ตรวจหลังปั่น | เบ้าเฟืองไม่สึก แหวนแน่น ไม่มีรอยร้าว |

## ค่าที่ยังเป็นค่าประมาณ (ใช้งานได้แล้ว แต่ยังไม่ได้วัดจริง)

- **เส้นผ่านศูนย์กลางในของโถ:** 110 ที่ก้น / 125 ที่ปาก ระยะเหลือรอบข้าง 8.5 เกินเกณฑ์ 5 อยู่แล้ว
- **ขนาดสไลด์:** 75 × 25.4 หนา 1.0–1.2 ถ้าเปลี่ยนยี่ห้อ ให้ลองเสียบร่องก่อนใช้
- **ขนาด insert, รอบมอเตอร์ และความหนาแน่น PETG:** ใช้แค่ในการตรวจและการคำนวณ
